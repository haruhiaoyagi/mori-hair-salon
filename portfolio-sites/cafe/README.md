# KISSA NIDO — Cafe Website

自家焙煎コーヒーと季節の焼き菓子を扱う、小さな架空カフェの1ページWebサイトです。Web制作ポートフォリオとして制作しました。

## 制作目的

カフェの温度感や香りを視覚的に伝えながら、初めて訪れる人がメニュー・空間・営業時間を迷わず確認できる構成を目指しました。

## 使用技術

- HTML5
- CSS3（Grid / Flexbox / カスタムプロパティ / レスポンシブ）
- JavaScript（モバイルナビゲーション / デモ通知）
- GitHub Pages対応

## 工夫した点

- テラコッタ、マスタード、紙のようなベージュで焼き菓子とコーヒーの温かさを表現
- 雑誌・新聞を思わせる非対称なエディトリアルレイアウト
- 画像に依存せずCSSアートで独自のビジュアルを構成
- 48px以上のタップ領域、スキップリンク、Escapeキー操作に対応
- 架空店舗であることを常時明示し、外部機能はデモ通知に統一

## ファイル

- `index.html` — ページ構造とSEO・OGP
- `style.css` — デザインとレスポンシブ対応
- `script.js` — メニューとデモ通知
- `assets/og.png` — OGP画像
