# 蒼葉税理士事務所 — Tax & Advisory Website

創業支援と中小企業の経営伴走を行う架空税理士事務所を想定した、ポートフォリオ用1ページサイトです。

## 制作目的

専門性・正確性を担保しながら、税理士への相談を難しく感じる経営者にも「話しやすさ」が伝わるサイトを目指しました。

## 使用技術

HTML5 / CSS3 / JavaScript / GitHub Pages

## 工夫した点

- 深いネイビー、精密な罫線、整然としたグリッドで信頼性を表現
- 強み・サービス・代表者・料金を明快に整理
- 専門用語に頼らず、相談後の価値が伝わる文章設計
- 48px以上の操作領域、スキップリンク、Escapeキー操作に対応
- 架空資格・料金・所在地であることを明示
