# AXIS TRAINING — Personal Gym Website

完全予約制の架空パーソナルジムを想定した、Web制作ポートフォリオ用1ページサイトです。

## 制作目的

トレーニングの力強さだけでなく、論理的な指導と継続サポートへの信頼を伝え、無料体験へ自然につなげることを目的に設計しました。

## 使用技術

- HTML5 / CSS3 / JavaScript
- CSS Grid・Flexbox・レスポンシブデザイン
- GitHub Pages対応

## 工夫した点

- 黒と蛍光ライムによる高コントラストなブランド表現
- 大きな数字と見出しで成果・プログラムを短時間で把握できる情報設計
- 料金比較、トレーナー紹介、無料体験までの明快な導線
- スキップリンク、キーボード操作、十分なタップ領域に対応
- 実績値や予約機能が架空であることを明示
