# 日和整体院 — Body Care Website

肩や腰の不調を生活習慣から整える架空整体院を想定した、ポートフォリオ用1ページサイトです。

## 制作目的

身体に不安を抱える方が、施術内容・担当者・料金を安心して確認できる情報設計を目的に制作しました。

## 使用技術

HTML5 / CSS3 / JavaScript / GitHub Pages

## 工夫した点

- 淡い水色と生成り、丸い形状で清潔感と緊張を和らげる印象を表現
- お悩み→施術方針→担当者→料金→予約の順で不安を一つずつ解消
- 医療行為ではない旨と、架空情報であることを明示
- 48px以上の操作領域、スキップリンク、Escapeキー操作に対応
- CSSアートを用い、軽量で独自性のあるビジュアルを構成

## ファイル

`index.html` / `style.css` / `script.js` / `assets/og.png`
