# mori hair salon

東京・清澄白河の小さな美容室「mori hair salon」を想定した、スマートフォン対応の1ページWebサイトです。

> **ご注意**  
> 掲載している店舗名・住所・電話番号・スタッフ情報・料金はサンプルです。実際に利用する際は、実店舗の情報へ変更してください。

## 制作目的

個人経営の美容室を想定し、店舗の空気感と予約のしやすさを両立したWebサイトの制作実績として作成しました。  
落ち着いた時間を過ごしたい20〜40代のお客様を主なターゲットに、初めて訪れる方でも料金・スタッフ・場所を迷わず確認できる構成を目指しています。

**公開サイト:** https://haruhiaoyagi.github.io/mori-hair-salon/

## サイトの内容

- 店舗コンセプト
- 料金表
- スタッフ紹介
- アクセス・営業時間
- Instagramリンク
- Web予約・電話予約ボタン
- スマートフォン用ナビゲーション

## 使用技術

- HTML5：意味のある見出し構造とアクセシブルなマークアップ
- CSS3：Grid、Flexbox、カスタムプロパティ、レスポンシブデザイン
- JavaScript：スマートフォンメニュー、ダミーリンク案内、年表記の自動更新
- GitHub Pages：静的サイトの公開

フレームワークやビルドツールを使わず、HTML・CSS・JavaScriptだけで構成しています。

## 工夫した点

- 美容室の穏やかな雰囲気を、深いグリーンとベージュ、余白を活かしたレイアウトで表現
- 料金、スタッフ、アクセス、予約の順に、来店検討時の情報収集に沿った導線を設計
- スマートフォンでは画面下に予約ボタンを固定し、どこからでも予約欄へ移動可能
- メニューや主要ボタンに十分なタップ領域を確保
- 架空サイトであることを明示し、予約・電話・SNS・地図には誤操作を防ぐデモ表示を実装
- OGPとSNS用画像を設定し、ポートフォリオとして共有した際の見え方にも配慮
- キーボード操作、`aria`属性、動きを減らす端末設定に対応

## ファイル

- `index.html`：文章、料金、住所、リンクなど
- `style.css`：色、文字サイズ、余白、スマートフォン表示など
- `script.js`：スマートフォンメニュー、フッター年の自動更新
- `.nojekyll`：GitHub Pagesでそのまま配信するための設定
- `assets/og-image.png`：SNSで共有したときに表示されるOGP画像

## 店舗情報の変更方法

`index.html`をテキストエディタで開き、次のサンプル情報を実店舗の情報に置き換えてください。

1. 店舗名・コンセプト
2. 料金とスタッフ情報
3. 住所・営業時間・定休日
4. Instagram URL
5. Web予約URL（現在は `https://example.com/`）
6. 電話番号（表示文字と `tel:` の両方）
7. Google Mapsの検索URL

コード内に編集箇所のコメントがあります。

## ローカルで確認する方法

`index.html`をダブルクリックすると、ブラウザで表示を確認できます。
